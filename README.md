# Танчики 🎮

Браузерный клон классической игры Battle City (Dendy/NES), написанный на Phaser 3.

![Game Preview](https://img.shields.io/badge/Phaser-3.60-blue) ![Language](https://img.shields.io/badge/JavaScript-ES6-yellow) ![License](https://img.shields.io/badge/license-MIT-green)

## Геймплей

- 2 уровня с уникальными картами (после прохождения уровни повторяются с нарастающей сложностью)
- 3 типа врагов: обычные, быстрые, бронированные (3 HP)
- 5 жизней у игрока
- 5 HP у базы — орёл меняет цвет по мере получения урона и мигает при последнем HP
- Разрушаемые кирпичные стены, непробиваемая сталь, вода и лес

## Управление

| Действие | Клавиши |
|---|---|
| Движение | `W A S D` или стрелки `↑ ↓ ← →` |
| Огонь | `Пробел` или `Enter` |
| Рестарт | `R` |

## Запуск на Mac

### Способ 1 — Python (встроен в macOS, самый простой)

```bash
cd tanks-game
python3 server.py
```

Открой в браузере: **http://localhost:8080**

### Способ 2 — npx serve (если установлен Node.js)

```bash
cd tanks-game
npx serve .
```

### Способ 3 — Live Server в VS Code

1. Установи расширение **Live Server** (ritwickdey.LiveServer)
2. Правой кнопкой по `index.html` → **Open with Live Server**

> **Важно:** нельзя просто открыть `index.html` двойным кликом — браузер заблокирует загрузку скриптов через `file://`. Нужен локальный HTTP-сервер.

```

```

## Механики

- **Разрушение стен:** кирпич уничтожается пулей, сталь — нет
- **База (орёл):** 5 HP; цвет рамки и орла меняется с каждым попаданием (золотой → оранжевый → красный), на последней жизни мигает
- **Враги:** спавнятся сверху (3 точки), до 4 одновременно на поле; ИИ движется к базе
- **Пули:** отражаются/уничтожают друг друга при столкновении
